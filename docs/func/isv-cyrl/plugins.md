# Система плугинов

Плугины сут sidecar-процеси, котори комуницирајут с панелју чез Unix-сокети.
Сваки плугин јест самостојни HTTP-процес.

Плугины се ищут в `/etc/intermasq/plugins/`; сваки подкаталог содржи
`manifest.json` и бинар:

```json
{"id":"my-plugin","name":"My Plugin","bin":"./plugin-binary"}
```

`id` јест уникални и служи в URL `/plugins/<id>/*`; `bin` јест относни пут к
извршајемому фајлу. При запуску `plugins.Load` создаје каталог сокетов, чита
манифести, запуска бинар с `INTERMASQ_KEY` и `PLUGIN_SOCKET`, и монтује
reverse-proxy. При остановке `plugins.Stop` убива вси плугин-процеси.

Сви `/plugins/<id>/*` запроси проходет чез исту аутентификацију као API (JWT или
`X-API-Key`). Плугины не се перезапускајут автоматично; после измени манифеста
или бинару потребно рестартовати панел.
