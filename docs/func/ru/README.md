# Подробная документация Intermasq (RU)

Этот каталог — расширенные руководства. Главный `README.md` в корне репозитория
содержит только краткое описание и быстрый старт; всё, что требует подробностей,
живёт здесь.

| Файл | О чём |
|---|---|
| [os-setup.md](os-setup.md) | **Запуск под Linux: права, sudo, init-системы, systemd-юнит, каталоги.** Читать первым при развёртывании. |
| [api.md](api.md) | Полный список эндпоинтов, аутентификация (JWT / X-API-Key), RBAC (admin/user). |
| [features.md](features.md) | Возможности по доменам: DHCP/DNS, конфиг-редактор, история, массовые операции, безопасность, UX. |
| [plugins.md](plugins.md) | Система плагинов: manifest, окружение, reverse-proxy, жизненный цикл. |
| [metrics.md](metrics.md) | `/metrics` для Prometheus, DNS health-check, примеры алертов. |
