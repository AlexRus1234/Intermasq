## DHCP: статические хосты

- **CRUD `dhcp-host=`** с валидацией MAC / IP / hostname (`internal/validate`).
- **Опциональные поля на хосте:**
  - `tags` — набор квалификаторов после IP: `set:<tag>` (для таргетинга
    `dhcp-option`), `id:<client-id>` и другие нативные dhcp-host поля.
  - `lease_time` — суффикс времени аренды (`12h`, `3600`, `infinite`). Тянулся
    через bulk move/edit без потери.
- **Подсказка следующего IP** (`GET /api/hosts/next-ip`) — предлагает свободный
  адрес из известного `dhcp-range`.
- **Шаблоны хостов** — пресеты «имя + ip-диапазон + target-файл»; применяются
  одним действием к выбранному MAC (`POST /api/hosts/apply-template`).

MAC-формат: `^([0-9A-Fa-f]{2}[:-]){5}([0-9A-Fa-f]{2})$` (допускает `:` и `-`).

## DNS-записи

- Типы: **A** (`address=/domain/IP`), **CNAME** (`cname=alias,target`),
  **PTR**, **TXT**.
- CRUD + массовый импорт + CSV-экспорт/импорт.
- Домены, заведённые как A/CNAME, периодически резолвятся фоновым
  health-checker'ом → метрики `intermasq_domain_up{domain=…}` (см.
  [metrics.md](metrics.md)).

## Конфигурация dnsmasq

- **Визуальный редактор** директив: `dhcp-range`, `dhcp-option` (с пресетами по
  RFC 2132), `server=`/`server=/domain/upstream`, PXE / сетевая загрузка.
- **Raw-редактор** (`🎨 Visual / 📝 Raw`): прямое редактирование текста файла.
  Доступно только admin-роли (т.к. `PUT /api/files/:name` — admin).
- **Многофайловость:** работа с несколькими `.conf` одновременно; создание,
  удаление, переключение табами.
- **Пресеты конфига** (`GET /api/config/templates`): `basic-dhcp`, `forwarder`,
  `pxe`, `aliases`, `empty` — при создании нового файла.

## Безопасность и история

- **`.bak`** — быстрый undo на один шаг перед каждой записью
  (`POST /api/rollback`, admin).
- **Многоуровневая история** (`-history-dir`, `-history-depth`, по умолчанию 10
  версий на файл):
  - `GET /api/history` — список версий (новейшие первыми).
  - `GET /api/history/diff` — unified diff между версиями или с текущим файлом.
  - `POST /api/history/restore` — восстановить версию (admin). Текущее
    состояние при этом тоже сохраняется в историю → undo restore доступен.
  - Имена версий: `<sha256-путь>_YYYYMMDD-HHMMSS[-N].bak`. Path traversal
    невозможен (версия валидируется regex, путь — `IsSafePath`).
- **ZIP backup/restore** всех `.conf`; restore с pre-flight `dnsmasq --test` и
  автоматическим откатом при провале.
- **Защита путей:** `IsSafePath` запрещает всё вне `-conf-dir`; имена для raw
  редактора обязаны оканчиваться на `.conf` и не содержать разделителей.
- **Превалидация:** перед каждым применением изменений запускается
  `dnsmasq --test`; при ошибке файл откатывается, а счётчик
  `intermasq_dnsmasq_test_failures_total` растёт.

> Исключение: `POST /api/leases/to-static` намеренно **не** запускает
> `dnsmasq --test` — ради скорости массовой операции. UI предупреждает
> жёлтым баннером и подсказывает нажать «Применить».

## Массовые операции

- **Bulk-импорт** хостов и DNS (вставка текстом/CSV).
- **Bulk-move** — перенос хостов в другой `.conf`.
- **Bulk-edit** — замена префикса IP, суффикса/удаление hostname.
- **Lease → static** — массовый перенос аренд в статику.
- **Массовое удаление** чекбоксами.
- **CSV-экспорт/импорт** для хостов и DNS-записей.

## Обнаружение устройств

- **Новые устройства** — MAC из ARP, которых нет ни в статике, ни в арендах.
- **OUI-lookup** по встроенной таблице (`internal/oui`) определяет вендора по
  первым 3 октетам MAC (Apple, Cisco, Netgear, Raspberry Pi, QEMU/KVM и т.д.).
- Кнопка «Добавить» перекидывает в форму static с предзаполненным MAC.

## Эксплуатация и UX

- **Один бинарник** — фронтенд встроен через `go:embed frontend/dist/*`, ничего
  ставить на целевую машину не нужно.
- **Мульти-init** — автоопределение systemd / systemd-user / OpenRC / runit /
  sysvinit (см. [os-setup.md](os-setup.md)).
- **SSE в реальном времени** (`GET /api/events`) — пуш ARP и статуса dnsmasq
  только при изменении (без опроса). Канал broadcaster'а неблокирующий: медленный
  клиент просто пропускает обновление, не вешая остальных.
- **Двойная аутентификация** — JWT для браузера, `X-API-Key` для скриптов и
  плагинов.
- **RBAC в UI** — admin-кнопки (reload, rollback, raw-запись, users, restart)
  скрыты для роли `user`.
- **Swagger UI** из коробки (`/swagger/index.html`).
- **Двуязычный UI** — 🇷🇺 Русский / 🇬🇧 English, переключение в один клик.
- **🌙 Тёмная / ☀️ светлая тема** с сохранением выбора.
- **Аудит-лог** — все действия с цветными метками (создание/удаление
  пользователей, raw-правки, restore, backup и т.д.).
