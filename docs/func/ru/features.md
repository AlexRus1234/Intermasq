# Функциональные возможности

В документе описаны основные функциональные области системы. Краткий обзор
приведён в корневом `README.md`.

---

## DHCP: статические хосты

- Операции создания, чтения, изменения и удаления записей `dhcp-host=` с
  валидацией MAC, IP и hostname (`internal/validate`).
- Дополнительные поля хоста:
  - `tags` — набор квалификаторов после IP: `set:<tag>` для назначения
    `dhcp-option`, `id:<client-id>` и другие поля `dhcp-host`.
  - `lease_time` — суффикс времени аренды (`12h`, `3600`, `infinite`),
    сохраняемый при массовом перемещении и редактировании.
- `GET /api/hosts/next-ip` предлагает свободный
  адрес из известного `dhcp-range`.
- Шаблоны хостов содержат имя, диапазон IP и целевой файл; применяются
  одним действием к выбранному MAC (`POST /api/hosts/apply-template`).

MAC-формат: `^([0-9A-Fa-f]{2}[:-]){5}([0-9A-Fa-f]{2})$` (допускает `:` и `-`).

## DNS-записи

- Поддерживаются типы **A** (`address=/domain/IP`), **CNAME** (`cname=alias,target`),
  **PTR**, **TXT**.
- Поддерживаются стандартные операции, массовый импорт и импорт/экспорт CSV.
- Домены, заведённые как A/CNAME, периодически резолвятся фоновым
  health-checker'ом → метрики `intermasq_domain_up{domain=…}` (см.
  [metrics.md](metrics.md).

## Конфигурация dnsmasq

- Визуальный редактор поддерживает директивы `dhcp-range`, `dhcp-option` (с наборами по
  RFC 2132), `server=`/`server=/domain/upstream`, PXE / сетевая загрузка.
- Текстовый редактор обеспечивает прямое редактирование файла.
  Доступно только admin-роли (т.к. `PUT /api/files/:name` — admin).
- Поддерживается работа с несколькими `.conf`: создание,
  удаление, переключение табами.
- Пресеты конфигурации (`GET /api/config/templates`) включают `basic-dhcp`, `forwarder`,
  `pxe`, `aliases`, `empty` — при создании нового файла.

## Безопасность и история

- Перед каждой записью создаётся резервная копия `.bak`, позволяющая выполнить
  одношаговый откат
  (`POST /api/rollback`, admin).
- Многоуровневая история (`-history-dir`, `-history-depth`, по умолчанию 10
  версий на файл):
  - `GET /api/history` — список версий (новейшие первыми).
  - `GET /api/history/diff` — unified diff между версиями или с текущим файлом.
  - `POST /api/history/restore` — восстановить версию (admin). Текущее
    состояние при этом тоже сохраняется в историю → undo restore доступен.
  - Имена версий: `<sha256-путь>_YYYYMMDD-HHMMSS[-N].bak`. Path traversal
    невозможен (версия валидируется regex, путь — `IsSafePath`).
- Резервное копирование и восстановление всех `.conf` в формате ZIP выполняются
  с предварительной проверкой `dnsmasq --test` и
  автоматическим откатом при провале.
- `IsSafePath` запрещает операции за пределами `-conf-dir`; имена для текстового
  редактора обязаны оканчиваться на `.conf` и не содержать разделителей.
- Перед каждым применением изменений запускается
  `dnsmasq --test`; при ошибке файл откатывается, а счётчик
  `intermasq_dnsmasq_test_failures_total` растёт.

> Исключение: `POST /api/leases/to-static` намеренно **не** запускает
> `dnsmasq --test` — ради скорости массовой операции. UI предупреждает
> жёлтым баннером и подсказывает нажать «Применить».

## Массовые операции

- Массовый импорт хостов и DNS (текстовый формат или CSV).
- **Bulk-move** — перенос хостов в другой `.conf`.
- **Bulk-edit** — замена префикса IP, суффикса/удаление hostname.
- **Lease → static** — массовый перенос аренд в статику.
- **Массовое удаление** чекбоксами.
- **CSV-экспорт/импорт** для хостов и DNS-записей.

## Обнаружение устройств

- Новыми считаются MAC-адреса из ARP, отсутствующие в статических записях и арендах.
- **OUI-lookup** по встроенной таблице (`internal/oui`) определяет вендора по
  первым 3 октетам MAC (Apple, Cisco, Netgear, Raspberry Pi, QEMU/KVM и т.д.).
- Кнопка «Добавить» перекидывает в форму static с предзаполненным MAC.

## Эксплуатация и пользовательский интерфейс

- Фронтенд встраивается в исполняемый файл через `go:embed frontend/dist/*`;
  установка дополнительных компонентов на целевую машину не требуется.
- Реализовано автоопределение systemd / systemd-user / OpenRC / runit /
  sysvinit (см. [os-setup.md](os-setup.md)).
- SSE-поток (`GET /api/events`) передаёт изменения ARP и статуса dnsmasq
  только при изменении (без опроса). Канал broadcaster является неблокирующим:
  медленный клиент пропускает обновление и не блокирует другие соединения.
- Поддерживаются JWT для браузера и `X-API-Key` для скриптов и
  плагинов.
- Интерфейс разграничивает элементы RBAC: административные операции (reload,
  rollback, raw-запись, users, restart)
  скрыты для роли `user`.
- Интерактивная документация Swagger доступна по адресу `/swagger/index.html`.
- Интерфейс поддерживает русский и английский языки.
- Доступны тёмная и светлая темы с сохранением выбранного режима.
- Журнал аудита фиксирует действия пользователей (создание и удаление
  пользователей, raw-правки, restore, backup и т.д.).
