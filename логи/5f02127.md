# Сессия: исправление багов Lease→Static

## Коммит `5f02127` — Fix lease-to-static transfer and hide 'To Static' for known hosts

### Баг 1: При переходе с Leases в Stатику форма пустая

**Причина:** `LeasesTab.vue` записывал данные в `store.transferData` и переключал `store.tab = 'static'`. Но `StaticView` рендерился через `v-if`, и при маунте `HostForm.vue` watch на `transferData` не срабатывал — начальное значение уже было установлено, а подписка шла только на будущие изменения (не было `{ immediate: true }`).

**Исправление:**
- `HostForm.vue`: добавлен `{ immediate: true }` в watch на `store.transferData`
- `HostForm.vue`: `store.transferData = null` перенесён из `StaticView.vue` в `HostForm.vue` — очистка происходит после того, как форма данные прочитала
- `StaticView.vue`: убран дублирующий watch на `store.transferData` (раньше мог очистить данные до того, как HostForm их успеет прочитать)

### Баг 2: Кнопка "В статику" показывалась для уже добавленных хостов

**Причина:** В `LeasesTab.vue` кнопка "➕ В статику" рендерилась для каждого lease без проверки, есть ли MAC уже в `store.hosts`. Переключатель "Скрыть известные" скрывал строку целиком, но при выключенном переключателе кнопка была видна даже для существующих записей.

**Исправление:**
- `LeasesTab.vue`: добавлен `knownMacs` computed — `Set` из MAC-адресов `store.hosts` (в lowercase)
- `LeasesTab.vue`: если `knownMacs.has(l.mac.toLowerCase())` — показывается бейдж "✓ В статике" вместо кнопки
- `ru.json`: добавлен ключ `leases.inStatic` → "В статике"
- `en.json`: добавлен ключ `leases.inStatic` → "In static"
