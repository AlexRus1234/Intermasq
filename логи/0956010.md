## Коммит `54a5a2d` — SystemCaller, флаги, тесты

### Новый файл: `system.go`

- Интерфейс `SystemCaller` с методами `IsActive(service) bool` и `Restart(service) error`
- `SystemdSystemCaller` — системный scope, с/без sudo (root → без sudo, unprivileged → sudo -n)
- `SystemdUserCaller` — `systemctl --user` для CI и user-сессий
- `NoneCaller` — noop, всегда `true`/`nil` (для CI и без-systemd сред)
- `detectSystemCaller()` — автоопределение: root→system, sudo -n→system+sudo, systemctl --user→user, иначе→none
- `resolveSystemCaller(scope)` — парсит `--systemd-scope` (auto/system/user/none)
- `initSystemCaller()` — инициализация + логирование scope

### Изменён: `dnsmasq.go`

- `getArpTable()` → чтение файла по `*ArpPath` + вызов чистой функции `parseArpContent(string)`
- `parseArpContent(content string)` — парсит ARP-таблицу из строки, тестируема без файлов
- `checkDnsmasqStatus()` → `sysCaller.IsActive("dnsmasq")` вместо hardcoded `sudo systemctl`
- `reloadDnsmasq()` — сигнатура изменена с `([]byte, error)` на `error`:
  - `dnsmasq --test` stderr возвращается как `fmt.Errorf("%s", testOut)` при ошибке конфига
  - `sysCaller.Restart("dnsmasq")` вместо hardcoded `sudo systemctl restart`

### Изменён: `main.go`

- Новые флаги:
  - `--arp-file` (default `/proc/net/arp`) — путь к ARP-файлу
  - `--systemd-scope` (default `auto`) — auto/system/user/none
  - `--ci-mode` (default false) — disables self-restart на `/api/restart-self`
- `initSystemCaller(*SystemdScope)` вызывается в `main()` после `flag.Parse()`
- `/restart-self`: если `*CiMode` — не вызывает `systemctl restart intermasq`
- Лог: `Intermasq v3.0 Started on :%s` (убран "(Socket Mode)")
- Плагины: логи на английском (`Error starting`, `Started`)

### Изменён: `handlers.go`

- `reloadHandler`: `_, err := reloadDnsmasq()` → `if err := reloadDnsmasq(); err != nil`

### Новый файл: `dnsmasq_test.go`

- `TestParseArpContent` — парсинг 3 строк (2 активных, 1 с флагом 0x0)
- `TestParseArpContentEmpty` — только заголовок, 0 MAC
- `TestParseArpContentZeroMac` — фильтрация 00:00:00:00:00:00
- `TestParseArpContentUppercaseMac` — MAC приводится к нижнему регистру

## Коммит `0956010` — CI Pipeline

### `.forgejo/workflows/build.yml`

- Триггер: push/PR на `main`
- `runs-on: docker`, контейнер `golang:1.25-alpine`
- Шаги:
  1. Checkout
  2. Install nodejs+npm (apk)
  3. Build frontend (npm ci + vite build)
  4. Build Go binary
  5. `go vet ./...`
  6. `gofmt -l .` (формат-чек)
  7. `go test ./...`
  8. Smoke test: запускает intermasq с `--ci-mode --systemd-scope none --port 0`, ждёт 2s, kill
  9. Upload artifact (intermasq-linux-amd64)

### `.forgejo/workflows/release.yml`

- Триггер: `workflow_dispatch` с input `version`
- `runs-on: docker`, контейнер `golang:1.25-alpine`
- Шаги:
  1. Checkout
  2. Install nodejs+npm
  3. Build frontend
  4. Build Go binary с `-ldflags="-s -w -X main.version=${{ inputs.version }}"`, `CGO_ENABLED=0`
  5. `go vet ./...`
  6. `go test ./...`
  7. `sha256sum intermasq > intermasq.sha256`
  8. Upload to Forgejo Packages:
     - `https://git.yadr00.internal/api/packages/Build/generic/intermasq/${{ inputs.version }}/intermasq`
     - `+ intermasq.sha256`
     - Токен: `${{ secrets.UPLOAD_TOKEN }}`
  9. Upload artifact (intermasq + sha256)

### Вручную (не в коммите)

- Создать secret `UPLOAD_TOKEN` в Forgejo UI → Settings → Actions → Secrets
